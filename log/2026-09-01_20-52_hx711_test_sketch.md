## What was Created & Fixed

### 1. Dedicated Interactive 10kg Load Cell Test Utility
- Created [`hx711_calibration_test/hx711_calibration_test.ino`](file:///f:/PROJECT/IV_version2/hx711_calibration_test/hx711_calibration_test.ino).
- **Features**:
  - **Noise Filter (EMA)**: Implemented an Exponential Moving Average filter (`EMA_ALPHA = 0.25`) with deadband thresholding to eliminate the +/- 0.1 g / kg fluctuations.
  - **Auto-Calibration (`w <grams>`)**: Type e.g. `w 500` in the Serial Monitor with a 500g object placed on the load cell to automatically calculate and save the exact calibration factor.
  - **Interactive Factor Tuning**: Use `+` / `-` (or `a` / `z`) to adjust factor in real-time.
  - **Zero Tare**: Press `t` to zero scale.
  - **Dual Display**: Live telemetry on both Serial Monitor (9600 baud) and 16×2 LCD screen.
